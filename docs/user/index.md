# Langues disponibles

La langue principale du site est définie à l'installation.

Si le site propose plusieurs langues, vous pouvez sélectionner
l'une des langues activées par son administrateur. Une langue en
**préouverture** est encore en préparation : elle n'est pas visible
dans le choix des langues public.

Si le site n'a pas activé le multilinguisme, seule la langue
principale est disponible. Les noms affichés sont traduits dans
la langue de l'interface lorsque la traduction existe, sinon
ils apparaissent sous leur nom natif.

*Ce document décrit le référentiel et la visibilité des langues.
Le sélecteur propre à une application sera intégré à son interface
selon les fonctionnalités de celle-ci.*
